# BudgieOS Full

BudgieOS Full is a custom x86_64 operating-system starter project. It is **not Linux, BSD, or macOS**. The project uses a small freestanding C++ kernel, Assembly entry code, GRUB for the initial boot path, and a planned BudgieFS filesystem.

## Size targets

- **Installed-system target:** 4 GB (a design target; not included as a 4 GB download in this repository).
- **Source repository:** small text source files.
- **Bootable ISO:** generated by the build workflow; its size depends on included drivers, applications, and assets. It is not automatically 4 GB.

GitHub repositories should not store a 4 GB generated disk image. Build the ISO locally or publish release assets using an appropriate large-file distribution service.

## Current status

This is an early bootable-kernel scaffold, not a complete operating system. WNU, the shell, device drivers, memory manager, and BudgieFS are planned components and must be implemented and tested before claiming they work.

## Build on Ubuntu / Debian

```sh
sudo apt update
sudo apt install build-essential g++-multilib grub-pc-bin xorriso mtools
make
```

Output: `build/budgieos-full.iso`.

Run in VirtualBox or QEMU with an x86_64 VM. Start with 2 GB RAM and 2 virtual CPUs for testing; this is a VM test configuration, not a minimum requirement.

## Layout

- `boot/boot.asm` — Multiboot2 header and 32-bit-to-64-bit entry setup.
- `kernel/kernel.cpp` — minimal kernel entry and VGA text output.
- `linker.ld` — kernel memory layout.
- `Makefile` — compile and ISO build targets.
- `.github/workflows/build.yml` — CI build.

## Roadmap

1. Validate boot and print a kernel banner.
2. Add exception handling and serial logging.
3. Add physical memory-map parsing and a safe allocator.
4. Add paging and heap management.
5. Add storage drivers and BudgieFS.
6. Add WNU command shell and desktop services.
